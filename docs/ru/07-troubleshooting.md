# 07. Решение проблем

## `tguser: command not found`

Инструмент не установлен глобально либо каталог с исполняемым файлом не в `PATH`.

1. Установите инструмент: `uv tool install git+https://github.com/yerza06/tguser-cli.git`
   (или `uv tool install .` из корня клона — см. [01. Установка](01-installation.md)).
2. Проверьте, что он появился: `uv tool list` — в списке должен быть `tguser`.
3. Если инструмент установлен, но команда всё равно не находится, `~/.local/bin` отсутствует
   в `PATH`. Добавьте его: `uv tool update-shell`, затем перезапустите терминал.

Проверка: `which tguser` должен вывести путь вида `/home/<user>/.local/bin/tguser`.

## Изменения в коде не применяются / устаревшая версия

`uv tool install` копирует код в момент установки, поэтому новые коммиты в GitHub и правки в
локальном клоне не влияют на уже установленный инструмент. Переустановите его:

```bash
uv tool install git+https://github.com/yerza06/tguser-cli.git --force   # если ставили из GitHub
uv tool install . --force                                              # если ставили из клона
```

Либо поставьте клон в editable-режиме (`uv tool install -e .`) — тогда изменения подхватываются
сразу.

## «Нет учётных данных» — не заданы api_id/api_hash

```
✗ Нет учётных данных
Не заданы api_id/api_hash. Выполните: tguser login
```

Вы ещё не вводили api_id/api_hash. Запустите `tguser login` (он спросит их и сохранит)
или задайте переменные `TGUSER_API_ID` и `TGUSER_API_HASH` —
см. [03. Конфигурация](03-configuration.md).

## «Нет сессии» — нужно войти

```
✗ Нет сессии
Сессия не найдена. Сначала войдите: tguser login
```

Файл сессии `~/.config/tguser/tguser.session` отсутствует или был удалён. Выполните `tguser login`.

## Удалён `tguser.session` или `tguser.db`

Эти файлы удалять нельзя — в них хранится всё состояние инструмента, и автоматического
восстановления нет (разбор файлов — в
[03. Конфигурация](03-configuration.md#-файлы-tgusersession-и-tguserdb-нельзя-удалять)).
Если файл всё же удалён:

- **`tguser.session`** — авторизация потеряна. Выполните `tguser login` заново: понадобятся номер
  телефона, код из Telegram и облачный пароль (если включена двухфакторная защита). Старая сессия
  при этом остаётся в списке активных устройств аккаунта — завершите её вручную в приложении
  Telegram (*Настройки → Устройства*).
- **`tguser.db`** — все alias потеряны. База создастся заново пустой; имена чатов нужно добавить
  руками. Найти ID помогут `tguser dialogs` и `tguser resolve` (см.
  [08. Обнаружение чатов](08-discovery.md)), затем `tguser chat add <имя> <id>`.

Если у вас есть резервная копия каталога — просто верните файлы обратно в `~/.config/tguser/`,
пока `tguser` не запущен.

## «Нет файлов» — путь к файлу неверный

```
✗ Нет файлов
Не найдено ни одного существующего файла. Проверьте пути.
```

Команды отправки медиа считают контентом только **существующие** файлы. Если первый позиционный
аргумент не является файлом на диске, он воспринимается как цель, и контента не остаётся.
Проверьте, что пути к файлам указаны верно и файлы существуют.

## Отрицательные ID каналов и групп

ID групп и каналов в Telegram отрицательные (например, `-1001234567890`). Указывайте их **как есть**:

```bash
tguser chat add work -1001234567890
tguser send "Привет" --to -1001234567890
```

Экранировать или использовать `--` не нужно — инструмент корректно обрабатывает такие значения.

## «Чат … уже существует» / «Чат … не найден»

- При `chat add` имя alias должно быть уникальным. Если имя занято — выберите другое
  или замените ID через `tguser chat replace-id`.
- При `chat get-id/remove/rename/replace-id` имя должно существовать. Проверьте список:
  `tguser chat list`.

## «Лишние аргументы»

```
✗ Неверные аргументы
Лишние аргументы: …
```

Передано больше позиционных аргументов, чем ожидается. Напомним порядок для медиа:
`<файлы…> <цель> <подпись>` (цель и подпись — только если не заданы флагами `--to`/`--caption`).
См. [05. Отправка сообщений](05-sending.md).

## Команда не отправляет, но и ошибки нет

Убедитесь, что сессия действительна: `tguser whoami`. Если выводится ошибка — войдите заново
через `tguser login`. При проблемах с подключением проверьте интернет и доступность Telegram.
