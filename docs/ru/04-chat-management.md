# 04. Управление чатами

Команда `chat` управляет **именованными идентификаторами** чатов, групп и каналов —
по аналогии с `git remote`. Вместо того чтобы каждый раз указывать числовой ID вроде
`-1001234567890`, вы сохраняете его под понятным именем (alias) и используете это имя в `--to`.

Идентификаторы хранятся в базе SQLite `~/.config/tguser/tguser.db`.

## Обзор подкоманд

| Команда | Назначение |
|---------|------------|
| `tguser chat add <name> <chat_id>` | Добавить alias |
| `tguser chat list` | Показать все сохранённые чаты |
| `tguser chat get-id <name>` | Вывести ID по имени |
| `tguser chat replace-id <name> <new_id>` | Заменить ID |
| `tguser chat rename <old> <new>` | Переименовать alias |
| `tguser chat remove <name>` | Удалить alias |

> `tguser chat` без подкоманды равнозначно `tguser chat list`.

## Добавить чат

```bash
tguser chat add work -1001234567890
```

```
╭────────────── ✓ Готово ──────────────╮
│ Добавлен чат work → -1001234567890   │
╰───────────────────────────────────────╯
```

В качестве `chat_id` можно сохранить:

- числовой ID (для групп/каналов он отрицательный, например `-1001234567890`);
- `@username` (например, `@durov`);
- `me` — Избранное (сохранённые сообщения).

> Отрицательные ID указываются как есть — экранировать ничего не нужно.

## Список чатов

tguser chat list      # или просто: tguser chat

## Получить ID по имени

```bash
tguser chat get-id work
# -1001234567890
```

Удобно для скриптов: команда печатает только сам ID.

## Заменить ID

```bash
tguser chat replace-id work -100999
```

## Переименовать

```bash
tguser chat rename work team
```

## Удалить

```bash
tguser chat remove team
```
