# 01. Установка

## Требования

- **Python 3.13** (зафиксирован в `.python-version`).
- **[uv](https://docs.astral.sh/uv/)** — менеджер пакетов и окружений.
- Аккаунт Telegram и доступ к <https://my.telegram.org> для получения `api_id`/`api_hash`
  (см. [02. Авторизация](02-authentication.md)).

## Установка зависимостей

Из корня проекта:

```bash
uv sync
```

Команда создаст виртуальное окружение `.venv/`, установит все зависимости из `pyproject.toml`
и сам пакет `tguser` в editable-режиме.

## Проверка установки

```bash
uv run tguser --version      # tguser 0.1.0
uv run tguser --help         # дерево всех команд
```

Если вывод `--help` показывает команды `login`, `chat`, `send`, `sendphoto` и т.д. — установка прошла успешно.

## Запуск команды

В этой документации команды записаны как `tguser …`. При запуске из репозитория добавляйте `uv run`:

```bash
uv run tguser <команда> [аргументы]
```

> Чтобы вызывать просто `tguser` без `uv run`, установите инструмент глобально, например
> через `uv tool install .` из корня проекта.
