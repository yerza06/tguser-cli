# 05. Отправка сообщений

`tguser` умеет отправлять текст и разные типы медиа от имени вашего аккаунта.
Перед отправкой нужно [войти в аккаунт](02-authentication.md).

## Куда отправлять: цель (`--to`)

Цель — это получатель. Указывается через флаг `--to` или позиционно. Поддерживаются:

| Вид цели | Пример |
|----------|--------|
| Имя сохранённого чата (alias) | `--to work` |
| Числовой ID | `--to -1001234567890` |
| Username | `--to @durov` |
| Избранное (свои сообщения) | `--to me` |

Имена alias настраиваются командой `chat` — см. [04. Управление чатами](04-chat-management.md).
Не знаете числовой ID? См. [08. Обнаружение чатов](08-discovery.md).

## Два синтаксиса

Все медиа-команды принимают аргументы **двумя способами** — выбирайте любой:

```bash
# через флаги
tguser sendphoto a.png b.png --to work --caption "Фотографии"

# позиционно
tguser sendphoto a.png b.png work "Фотографии"
```

**Как разбираются позиционные аргументы:** идущие подряд в начале токены, которые существуют
как файлы на диске, считаются контентом; следующий токен — это цель (если не задан `--to`),
а токен после него — подпись (если не задана `--caption`).

> Поэтому если файла по указанному пути нет, он будет ошибочно принят за цель. Проверяйте пути.

## Обзор команд

| Команда | Что отправляет | Подпись (`--caption`) |
|---------|----------------|:---------------------:|
| `send` | Текстовое сообщение | — (доп. текст) |
| `sendfile` | Файл(ы) как документ | ✓ |
| `sendphoto` | Фото (несколько — альбомом) | ✓ |
| `sendvideo` | Видео (несколько — альбомом) | ✓ |
| `sendaudio` | Аудио / музыка | ✓ |
| `sendvoice` | Голосовое сообщение | ✓ |
| `sendvideonote` | Видео-кружок | — |
| `sendsticker` | Стикер (`.tgs`/`.webp`) | — |
| `sendcontact` | Контакт | — |

## Текст

```bash
tguser send "Привет!" --to work
tguser send "Привет!" work            # позиционно
```

Флаг `--caption` для текста необязателен; если он задан, его значение добавляется к сообщению
через пустую строку:

```bash
tguser send "Заголовок" --to me --caption "Подробности ниже"
```

## Файлы (документы)

```bash
tguser sendfile report.pdf --to work --caption "Отчёт"
tguser sendfile a.zip b.zip --to work          # несколько документов
```

## Фото

```bash
tguser sendphoto photo.png --to me --caption "Скриншот"
tguser sendphoto p1.png p2.png p3.png --to work --caption "Галерея"
```

При двух и более файлах фото отправляются **альбомом**; подпись применяется к первому фото.

## Видео

```bash
tguser sendvideo clip.mp4 --to me --caption "Запись"
tguser sendvideo a.mp4 b.mp4 --to work          # альбом
```

## Аудио / музыка

```bash
tguser sendaudio track.mp3 --to me --caption "Трек"
tguser sendaudio one.mp3 two.mp3 --to me        # несколько треков
```

## Голосовое сообщение

```bash
tguser sendvoice voice.ogg --to me --caption "Голосовое"
```

## Видео-кружок

```bash
tguser sendvideonote note.mp4 --to me
```

## Стикер

```bash
tguser sendsticker sticker.webp --to me
```

## Контакт

Отправка контакта (имя + номер телефона):

```bash
# через флаги
tguser sendcontact --phone +77001234567 --first-name Иван --last-name Петров --to work

# позиционно: <phone> <first> [last] <target>
tguser sendcontact +77001234567 Иван Петров work
tguser sendcontact +77001234567 Иван work          # без фамилии
```

| Флаг | Описание |
|------|----------|
| `--phone` | Номер телефона (обязателен) |
| `--first-name` | Имя (обязательно) |
| `--last-name` | Фамилия (необязательно) |
| `--to` | Цель |

## Результат

При успешной отправке выводится панель:

```
╭──────── ✓ Готово ────────╮
│ Отправлено в work        │
╰───────────────────────────╯
```

Если что-то пошло не так — см. [07. Решение проблем](07-troubleshooting.md).
