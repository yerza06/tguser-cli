# 02. Авторизация

Чтобы отправлять сообщения от имени пользователя, нужно один раз войти в аккаунт.
`tguser` использует MTProto через Kurigram, поэтому требуются `api_id` и `api_hash`.

## Шаг 1. Получите api_id и api_hash

1. Откройте <https://my.telegram.org> и войдите под своим номером телефона.
2. Перейдите в раздел **API development tools**.
3. Создайте приложение (любые название и описание).
4. Скопируйте **api_id** (число) и **api_hash** (строка).

> Эти данные — секретные. Не публикуйте их и не коммитьте в репозиторий.

## Шаг 2. Войдите в аккаунт

```bash
tguser login
```

Команда спросит по очереди:

- `api_id` и `api_hash` — если они ещё не заданы (будут сохранены в `~/.config/tguser/.env`);
- номер телефона в формате `+7…`;
- код подтверждения из Telegram;
- пароль двухфакторной аутентификации — **только если он включён**.

При успехе выводится панель с именем, username и id аккаунта.

### Передать параметры заранее

Можно указать значения флагами, чтобы не вводить их интерактивно:

```bash
tguser login --api-id 1234567 --api-hash 0123456789abcdef0123456789abcdef --phone +77001234567
```

| Флаг | Описание |
|------|----------|
| `--api-id` | api_id с my.telegram.org |
| `--api-hash` | api_hash с my.telegram.org |
| `--phone` | Номер телефона |

Код подтверждения и пароль 2FA всё равно запрашиваются интерактивно.

## Проверить текущий аккаунт

```bash
tguser whoami
```

Выводит таблицу: ID, имя, username, телефон.

## Выйти из аккаунта

```bash
tguser logout
```

Завершает сессию на сервере Telegram и удаляет локальный файл сессии
`~/.config/tguser/tguser.session`.

## Где хранится сессия

После входа создаётся файл сессии `~/.config/tguser/tguser.session`. Пока он существует и
действителен, повторный `login` не нужен — команды отправки работают сразу.

> ⚠️ **Этот файл нельзя удалять.** В нём хранится ключ авторизации Telegram; без него все команды
> перестанут работать, и потребуется заново пройти интерактивный `tguser login` (телефон, код,
> облачный пароль). Чтобы выйти из аккаунта, используйте `tguser logout` — он корректно завершает
> сессию на сервере Telegram и сам удаляет файл. То же касается базы чатов
> `~/.config/tguser/tguser.db`. Разбор обоих файлов — в
> [03. Конфигурация](03-configuration.md#-файлы-tgusersession-и-tguserdb-нельзя-удалять).

Подробнее о расположении файлов и переменных — в [03. Конфигурация](03-configuration.md).
