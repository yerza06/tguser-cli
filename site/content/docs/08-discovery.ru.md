Чтобы отправить сообщение или сохранить alias, обычно нужен идентификатор чата. Telegram
**не показывает** числовой ID (`-100…`) в интерфейсе, поэтому `tguser` помогает его узнать
двумя командами. Для обеих нужна активная сессия — сначала [войдите](02-authentication.md).

## `tguser dialogs` — список ваших диалогов

Показывает все чаты, в которых вы состоите (личные, группы, **закрытые** группы и каналы),
вместе с их числовыми ID.

```bash
tguser dialogs                 # все диалоги
tguser dialogs --search proj   # фильтр по названию или @username
tguser dialogs --limit 50      # ограничить количество
```

```

┃ ID чата        ┃ Название     ┃ Тип     ┃ @username ┃
┡━━━━━━━━━━━━━━━━╇━━━━━━━━━━━━━━╇━━━━━━━━━╇━━━━━━━━━━━┩
│ -1001234567890 │ Project Team │ channel │ —         │

└────────────────┴──────────────┴─────────┴───────────┘
```

| Опция | Краткая | Описание |
|-------|---------|----------|
| `--search` | `-s` | Фильтр по подстроке в названии или @username |
| `--limit` | `-n` | Сколько диалогов запросить (по умолчанию 100) |

## `tguser resolve` — узнать ID по @username или ссылке

```bash
tguser resolve @durov
tguser resolve "https://t.me/durov"
tguser resolve "https://t.me/+AbCdEf123456"   # приватная инвайт-ссылка
```

```
╭──────── ✓ Чат найден ────────╮
│ Pavel Durov (private)        │
│ ID: 123456789               │
╰───────────────────────────────╯
```

## Закрытая группа или канал без @username

У приватных чатов нет публичного `@username`. Узнать их ID можно так:

1. **`tguser dialogs`** — вы **участник** такого чата, значит он есть в списке диалогов.
   Отфильтруйте по названию: `tguser dialogs -s <часть названия>` — и скопируйте ID.
2. **Инвайт-ссылка** `t.me/+…` — если у вас есть пригласительная ссылка, передайте её
   в `tguser resolve "https://t.me/+…"`.

## Сохранение найденного чата

Узнав ID, сохраните его под именем (см. [04. Управление чатами](04-chat-management.md)):

```bash
tguser chat add team -1001234567890
```

Либо сразу передайте `@username` или ссылку в `chat add` — при активной сессии ID и название
подтянутся автоматически:

```bash
tguser chat add news @somechannel
```
